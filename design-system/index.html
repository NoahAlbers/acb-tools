Voice & writing

How it sounds

Professional but warm and plainspoken. Short sentences, zero fluff. We talk to landlords and property managers like peers.

DoLead with free, no signup, no email. Use short, confident sentences. Bring credibility hooks (25+ years, $85M+ recovered) sparingly, usually in the CTA.
AvoidLegalese outside generated documents. Hype words and filler. Em dashes and en dashes anywhere in copy; use commas, "to" for ranges, or a middot.

Standard disclaimer for calculators: estimates only, not financial advice. For document generators: not legal advice, review with a local attorney, laws change so verify current requirements.

Usage

Build with the tokens

Everything here is driven by CSS custom properties. Pull in tokens.css (or copy the :root block) and reference variables instead of raw hex, so the whole system stays consistent.

/* example */
.btn-primary {
  background: var(--acb-blue);
  color:#fff; border-radius: var(--acb-r-pill);
  box-shadow: var(--acb-shadow-blue);
  font-family: var(--acb-font);
}

Companion files in this folder: tokens.css (the variables) and README.md (the written spec, including the per-tool block order and engineering rules). The deeper brand and engineering guide lives in docs/brand-style-guide.md.
